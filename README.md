# Algorithms and Data Structures
This repository contains my solutions for the laboratories of the "Algoritmi e Strutture Dati" course at Politecnico di Torino Italy (Academic Year 2025/2026).

## 📂 Project Structure
* **Block 1 (`s326596_1`)**: Labs 01-03
* **Block 2 (`s326596_2`)**: Labs 04-06
* **Block 3 (`s326596_3`)**: Labs 07-09
* **Exam (`s326596`)**: 26/01/2026

## 🛠 Skills & Tools
* **Language**: C (C99 Standard)
* **Focus**:
    * **Memory Management**: Static, stack, and dynamic allocation (malloc/free).
    * **Recursion & Backtracking**: Implementation of recursive functions and state-space exploration.
    * **Data Structures & ADTs**: Linked lists, stacks, FIFO queues, priority queues (heaps), and Symbol Tables (BST, Hash Tables).
    * **Algorithmic Paradigms**: Divide et Impera, Dynamic Programming, and Greedy algorithms.
    * **Graph Theory**: Graph representations, DFS/BFS visits, Shortest Paths (Dijkstra), and Minimum Spanning Trees (MST).
    * **Software Engineering**: Modular programming (interface/implementation), Makefile, and debugging with GDB.
